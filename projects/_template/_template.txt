# =====================================================================
#  HOW TO ADD A NEW PROJECT
#   1. Copy the projects/_template folder and rename it,
#      for example:  projects/line-follower-robot/
#   2. Rename _template.txt inside the new folder to line-follower-robot.txt.
#      (the file name becomes the page name: project-line-follower-robot.html)
#   3. Put this project's images in the same folder.
#   4. Fill in the parts below and save.
#   5. Build again (or upload to GitHub, it builds by itself).
#  The new project shows up by itself on the Projects page, on the home page,
#  in the footer. The "hands-on projects" number on the home page goes up.
#
#  Folders that start with an underscore (like this one) are ignored.
#  Delete a project folder and its page disappears on the next build.
# =====================================================================
